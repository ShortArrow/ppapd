# ppapd ロードマップ

## 未決事項

影響の大きい順に並べる。決まったものは要件定義書（[PRD.md](PRD.md)）かアーキテクチャ（[ARCHITECTURE.md](ARCHITECTURE.md)）に反映し、ここから消す。

1. **「直近」の範囲**: PRD の F-3.1 で、何分以内、または何通以内を「直近」とするか。待機中の ZIP の記録とパスワード候補をいつ破棄するか。同じ組織で照合するときは候補が増えるので、同じ送信者より短くするか。
2. **メッセージの形式**: PRD の §7 にあるメッセージの項目と応答の形式を定める。
3. **待機中・失敗・不一致の表示**: PRD の F-2.4 のバッジの色と文言。
4. **リポジトリ名**: 扱う範囲が PPAP より広くなったので、`ppapd` のままでよいか。
5. **ブラウザ拡張の配布**: ストアで公開するか、デベロッパーモードでの読み込みだけにするか（ADR 003）。
