# ppapd

Outlook on the web で受け取ったファイルを、`<プロジェクト>\<送信者>\<受信日>\` のフォルダへ自動で振り分ける Windows 用のツールです。メールの添付、本文のダウンロードリンク（OneDrive を含む）、PPAP を扱います。

PPAP は、パスワード付き ZIP をメールで送り、そのパスワードを別のメールで送る受け渡し方式です。ppapd は受け取る側の手作業を減らすためのもので、PPAP の利用を勧めるものではありません。

> [!NOTE]
> 要件を定めている段階で、まだ動くものはありません。

## 何をするか

1. Outlook on the web でメールを開くと、ブラウザ側の部品が添付と本文中のパスワード候補を拾い、ローカルのデーモンへ渡します。
2. 本文のリンクからダウンロードしたファイルは、決まったダウンロードフォルダに保存されたものをデーモンが受け取ります。リンク先のログインはブラウザで行います。
3. ZIP は展開し、PPAP のパスワード付き ZIP はパスワードのメールと対応付けて解凍します。
4. `rules.yaml` に書いた規則（件名、送信者ドメインなど）でプロジェクトと送信者名を決め、そのフォルダへ書き出します。
5. メール一覧では、配送済みのメールにバッジが付きます。クリックすると配送先フォルダが開きます。

Microsoft Graph API やアプリ登録は使いません。組織の IT 管理者の承認がなくても、利用者が自分の PC に入れるだけで動くことを目指しています。

## 構成

| 部品 | 役割 |
| --- | --- |
| ブラウザ連携 | Chrome と Edge の拡張機能（Manifest V3）。Outlook on the web 上で動き、メールの情報とファイルをデーモンへ送る |
| デーモン | C#（.NET の最新 LTS 版）で書いたプロセス。ブラウザ拡張から起動され、展開と配送を行う |

## 扱うデータ

- 添付、本文、パスワードは、配送先へ書き出すファイルを除いてディスクに保存しません。処理中のメモリにだけ置きます。
- 送信者のアドレスとドメインは、このPC専用の鍵を使った HMAC-SHA256 で記録します。

## 対応環境

- Windows
- Outlook on the web（`https://outlook.office.com`）

ppapd は Microsoft とは関係のない個人のプロジェクトです。
